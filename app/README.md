# Impara 🇮🇹 — Italian Trainer (static web game)

A tap-only, mobile-first Italian study game. **No backend**: the whole app is static files + JSON, and all per-user progress lives in the browser's **IndexedDB**. Built to run on **GitHub Pages**.

The question bank follows the **Fluent Forever** method (pronunciation-adjacent drills, images-over-translation via emoji, recall-first flashcards, high-frequency-first, spaced repetition).

---

## Run locally

The app uses `fetch()` to load its data, so it must be served over **HTTP** — opening `index.html` with `file://` will fail.

```bash
cd app
python3 -m http.server 8791
```

Then open `http://localhost:8791`.

## Deploy to GitHub Pages

1. Put the **contents of this `app/` folder** at the root of a GitHub repo (or in a `/docs` folder).
2. Repo → **Settings → Pages** → Source = your branch, folder = `/` (or `/docs`).
3. Visit `https://<user>.github.io/<repo>/`.

That's it — everything is self-contained and relative-pathed. No build step, no server.

> Tip: on iOS/Android, "Add to Home Screen" gives a full-screen app-like experience.

## What's inside

```
app/
├── index.html          # 3 screens: home / study / summary
├── assets/
│   ├── style.css       # mobile-first, light+dark theme-aware
│   └── app.js          # engine: data load, SRS, 10 format renderers
└── data/
    ├── index.json      # manifest: levels, chunk filenames, counts, item ids
    ├── bank_A1.json    # ~1,987 items   (chunked by CEFR level for lazy-load)
    ├── bank_A2.json    # ~1,516 items
    ├── bank_B1.json    # ~1,051 items
    └── bank_B2.json    # ~457 items
```

**~5,011 items total**, levels **A1–B2**. The game lazy-loads one level chunk at a time. Study one level at a time, or use **Mixed review** (home screen) for spaced repetition across all levels.

### Question formats (10)
1 flashcard (emoji→word, self-graded recall) · 3 word→picture(emoji) MC · 4 cloze · 5 gender/article sort · 6 error-correction · 7 letter-tile spelling · 8 sentence-building · 9 reading comprehension · 10 transformation drill · 11 matching pairs.
*(Format 2, audio minimal-pair discrimination, is still omitted — but the build is no longer silent: 882 items carry native-speaker clips and the rest use `it-IT` TTS. See Audio below.)*

### Progress & spaced repetition
- IndexedDB DB `impara-it`, store `prog`, keyed by the item's stable `id`.
- Simple **Leitner** scheduler: correct → advance a box (longer interval), wrong → back to box 0. Flashcard self-ratings (Again/Hard/Good/Easy) map to box moves.
- Item `id`s are **stable** across bank rebuilds (assigned deterministically), so progress survives content updates.
- "Reset all progress" on the home screen clears the store.

### Silent mode
Toggle on the home screen. It hides any `audio: "required"` item and renders `enhanced` items in their text form. Because this build is entirely `silent`/`enhanced`, **everything is playable audio-off** — the ≥0.5 silent-ratio floor is met by construction (ratio = 1.0).

## Audio (native clips + TTS fallback)

**Done (2026-08-16).** **882** items carry **native-speaker recordings** fetched from
**Wikimedia Commons** (Lingua Libre + Wiktionary, all free licenses) and stored under
`media/audio/<theme>/<word>.{m4a,ogg}`; those items are `audio:"enhanced"` with a real
`prompt.audio_ref`. The other **166** catalogued words had no free native clip and fall back to the
browser's **`it-IT` Web Speech (TTS)** at play time — so the 🔊 **Ascolta** button is present and
audible on every word, clip or not.

- **How it was fetched/wired:** [`../05_audio_native/FETCH_PLAN.md`](../05_audio_native/FETCH_PLAN.md);
  scripts `../build/fetch_audio.py` + `../build/wire_audio.py` (resumable).
- **Credits (required for CC-BY / CC-BY-SA):** [`media/audio/ATTRIBUTIONS.md`](media/audio/ATTRIBUTIONS.md)
  and `../build/deliverables/audio_credits.json`.
- **Remaining gaps:** `../build/deliverables/audio_gap_report.json` (166 words). Re-run
  `python3 ../build/fetch_audio.py` any time to retry them — it resumes from `../build/audio_cache.json`.
- **Engine:** `assets/app.js` — the 🔊 button plays `audio_ref` if present, else speaks the lemma via
  `speechSynthesis` (`it-IT`). Silent mode still suppresses all audio.

Minimal-pair (format 2) ear-training can then be generated from `../build/lex/phono_sets.json` once multi-speaker audio exists.

## Rebuilding / extending the bank

The bank is generated by `../build/build_bank.py` from item JSON in `../build/items/`. To regenerate after editing/adding items:

```bash
cd ..
python3 build/build_bank.py
```

It validates every item against the frozen contract (`build/SCHEMA.md`), dedupes, assigns stable ids, chunks by level into `app/data/`, and refreshes the coverage ledger, media manifest, and review queue in `build/deliverables/`.
